# 29. Divide Two Integers 

## Problem overview

Topics and the description suggest that we should use bit manipulation for this
problem as we are not supposed to use multiplication/division opeators. So first
thought is to explore bit manipulation techniques a little to understand what we
might have at our arsenal to tackle the problem. Thorough googling led me to this
notorious link of the article about bit manipulation tricks
['Bit Twiddling Hacks'](https://graphics.stanford.edu/~seander/bithacks.html) which
is imo super useful material and we'll return to it later. The second great resource
that I stumbled upon is ['Labuladong Algo Notes'](https://labuladong.online/en/algo/frequency-interview/bitwise-operation/)
which is a great summary of many bit manipulation tricks with examples in C++. The
second part of a recipe for this problem is *a division algorithm* itself, be it either
long division or anything else.

Also want to mention the topics/chapters from these books/resources that might be helpful for basic understanding in terms of computer arithmetic, two's-complement and unsigned binary notation, boolean algebra and etc.:

* "Computer Systems A Programmer's Perspective", R E Bryant, 3rd ed.
	* Chapter 2: Representing and Manipulating Information
* "Computer Organization and Design: The Hardware/Software Interface", D A Patterson, 4th ed.
	* Chapter 3: Arithmetic for Computers
* "Computer Arithmetic: Algorithms and Hardware Designs", B. Parhami, 2nd ed.
	* Chapter 13: Basic Division Schemes
* "The Art of Computer Programming", Vol. 2 / Seminumerical Algorithms, D. Knuth, 2nd ed.
	* Chapter 4.3.: Multiple-precision arithmetic
